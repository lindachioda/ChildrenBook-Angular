# 📖 Children Book App

**Children Book App** is an Angular practice project designed as a simple online bookstore for children’s books.
Users can browse the available books, view their details, and add books to their shopping cart. By logging in with their credentials, users can access their personal area, manage the items in their cart, and proceed with the payment process.

This project was created as a practical exercise to develop and strengthen skills in **Angular, TypeScript, component-based development, routing, authentication, HTTP requests, API integration, and responsive web design**.

## Features

* Browse available children's books
* Add and manage books in the shopping cart
* User login and authentication
* Access to a personal area after login
* Payment process management
* Data management through a JSON Server API
